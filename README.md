# Signature Interior

A luxury interior design portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern, elegant design with smooth animations
- 📱 Fully responsive layout
- 🖼️ Beautiful portfolio gallery with filtering
- ✨ Framer Motion animations
- 🎯 SEO optimized
- ⚡ Fast performance with Next.js 14

## Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm (or npm/yarn)

### Installation

```bash
# Install dependencies
pnpm install
```

### Development

```bash
# Start development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Build

```bash
# Build for production
pnpm build

# Start production server
pnpm start
```

## Project Structure

```
src/
├── app/              # Next.js app directory
├── components/       # React components
├── data/            # Static data (services, gallery, testimonials)
├── styles/          # Global styles and animations
├── hooks/           # Custom React hooks
├── utils/           # Utility functions
└── config/          # Configuration files

public/
├── images/          # Image assets
└── icons/           # SVG icons
```

## Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
